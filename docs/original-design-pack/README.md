# Elzatona — AI Coding Agent Pack (Playful Academic v3)

## Files

- `AGENTS.md` — short non-negotiable rules for coding agents.
- `Elzatona_Implementation_Blueprint_v3.md` — updated architecture, flows, RLS, phases and acceptance tests.
- `ELZATONA_DESIGN_SYSTEM.md` — exact branded UI direction, screen specs and UX guardrails.
